二、要搭建的 3 个智能体方向（按当前实操优先级）

项目已经从"先图片后视频"推进到双线实操：视频侧能产出部分可用片段，现在要解决口播 / 对口型方案、上下文重发规则和行业知识库沉淀；图片侧继续稳定控制发色、品牌色和卖点数量。下一步不是盲目新增方向，而是把视频和图片两条线压到稳定可复用。

① 假发视频生成链路

痛点：视频素材量不够，旧素材反复剪；客户已能用 Lovart / seedance 出 1-2 条可用片段，但口播匹配、发际线自然度和素材一致性仍不稳定。
角色设定：跨境假发短视频导演，专门把爆款视频拆成脚本、镜头、台词和素材卡，适配 seedance / 即梦 / Lovart
输入：爆款视频逻辑 + 产品图 + 角色卡/产品卡/场景卡 + 口播文案
输出：中文结构化视频提示词、逐镜头生成清单、可用于投放测试的 AI 片段
当前首战W5视频实操

② 主图/卖点稳定智能体

痛点：不用智能体单独改图时发色能保持；一用主图智能体，发色、主题色和卖点数量容易跑偏。根因不是单纯模型问题，而是指令存在符号、负向表达和泛化规则。
角色设定：假发主图质量控制官，严格保留产品发色/发丝/蕾丝，按产品类型读取卖点知识库，输出不超过 4 个卖点
输入：产品图 + 产品类型（如 13x4 蕾丝）+ 品牌色规范 + 卖点知识库
输出：不跑色、不乱用品牌色、卖点数量可控的主图方案
W5-W6质量稳定

③ 每周素材复盘工作流

痛点：AI 素材能不能替代红人，最终不能靠主观判断，要进入 Meta 投放数据：哪些片段可用、哪些主图跑量、哪些指令需要迭代。
角色设定：素材增长分析师，把 AI 生成结果、人工审核和投放数据串成每周素材复盘
输入：本周 AI 图片/视频样例 + 人工审核记录 + CTR/ROAS/消耗数据
输出：每周 HTML 素材报告，告诉团队保留什么、淘汰什么、下周怎么改指令

三、把智能体打包成 Skill（团队人人能用，跨场景复用）

Skill 就是你们工厂的"工艺 SOP"——不是每次都重新教新员工，而是把标准动作固化下来。张兆清用一次之后，下一个同学输一个词就能复用，许昌和深圳的团队共享一套 AI 方法论。

Skill 1 · 假发视频提示词

触发词：/假发视频提示词
能力：输入爆款逻辑、产品卡和口播文案，输出适配 seedance / 即梦 / Lovart 的中文结构化提示词
复用：每个新品只换产品卡和卖点，视频脚本结构可反复复用

Skill 2 · 假发主图质检

触发词：/假发主图质检
能力：检查主图指令是否会导致发色、品牌色、卖点数量跑偏，并给出机器可执行改写
复用：所有主图智能体上线前先过质检，减少模型误读

Skill 3 · 素材周报

触发词：/素材周报
能力：汇总本周 AI 图片/视频样例、人工审核和投放数据，生成 HTML 复盘报告
复用：Meta、TK、亚马逊素材都可以按同一格式复盘

四、把 Skills 串成工作流，产出可交付的素材报告

图片素材批产工作流是第一个可以量化产出的闭环：每周花 2 小时用 AI，产出当周所有 Meta 测试图，全部留档追踪数据，好的加量，差的迭代指令。

工作流 · 每周 Meta 素材批产（示例）
📸 本周产品图/视频样例 → /假发视频提示词 → seedance/即梦/Lovart 测试 → /假发主图质检 → 人工审核 + 投放 → 📊 /素材周报 → 📤 投放 Meta + 数据追踪
每周交付物（素材报告）
· 本周产出图片/视频数量与合格率（人工审核通过比例）
· 视频模型对比：seedance / 即梦 / Lovart 哪个更适合当前产品
· 发色、发际线、品牌色、口播匹配问题记录 → 下周指令迭代方向
· 对比数据：AI 素材 vs 红人素材的 Meta 投放 CTR / ROAS（待积累后加入）

六、陪跑承诺

① 落地承诺
每次执行会议都让你看到可用的东西，不是讲理论。Lion 组（Lion + 林韩 + 考拉）三人并行：策略方向、技术教学、基础认知三条线同时跑，不让任何一个问题卡住进度。
② 复刻承诺
"AI 擅长复刻和复制已在市场拿到结果的东西。"（Lion 2026-06-09 会议原话）先把你们已验证的爆款素材逻辑固化成智能体，再横向铺开到新品、新渠道——不赌创意，只复刻被市场验证的结果。
③ 团队培养承诺
"感兴趣就从前往后看，全部开放给大家。"（考拉 2026-06-16 会议原话）每个阶段配套课程，做图同学、AI 负责人、老板各有专属学习路线；贪多嚼不烂，一节课一节课帮团队建立 AI 体感。
