一、先建立对 AI 的正确认知

你们的工厂强在原料采购、生产经验、产品开发，弱在销售端——独立站经验、品牌理解跟不上，导致散单为主、爆款不集中。素材端是这个短板的最痛处：找红人寄样一个假发 100-150 美金、合作费 100-500 美金，单条素材成本可达 500 美金，而且优质素材量还不够。AI 不是凭空造素材，而是把市场上已经验证过的爆款素材当模板，复刻出你国内拍不出来的国外模特素材——花花老师在会上说得很清楚：「AI 最擅长的是复刻和复制，不是凭空生成，而是找到那些已经在市场上拿到过结果的东西，让 AI 去分析它成功在哪里，再来做复制。」

二、要搭建的 3 个智能体（按首战板块优先级）

会上达成的共识：第一阶段聚焦素材端，亚马逊运营类智能体先不作为重点；先以独立站 LB（Amanda hair 站）为试点，先图片、后视频，跑通一个模块再横向铺开。所以智能体按「图片 → 视频 → 爆款分析引擎」推进，第三个是给前两个供锚点、并能跨渠道复用的底座。

① AI 图片素材智能体（Meta/Facebook 图文）

痛点：李总自述「一个假发成本 100-150 美元，跟红人合作 100-500，加起来可能得 500 美金……所以我想借助 AI 这种工具看能不能提高一下」；亚裔面孔出镜影响账号受众，本地黑人模特又难找。
角色设定：跨境假发 Meta 图文素材设计师，懂黑人女性蕾丝头套审美 + Meta 图文爆款结构。
输入：高消耗爆款图片 + 数据、产品款式信息、目标人群。
输出：可直接投 Meta/Facebook 的图文素材（替代国外模特拍摄）。
阶段 5W3-W4首战

② AI 视频素材智能体（Meta 视频）

痛点：找红人视频「费用特别高、优质素材和视频量不够、内容也不行」；许昌本地几乎没有做内容的商家，自制视频局限大。共识是不做纯 AI、要 AI+真人混剪。
角色设定：以爆款模板为基底的视频素材补充师（前 3 秒钩子→产品特写→达人/场景混剪）。
输入：图片素材 + 达人原素材 + 爆款视频结构模板。
输出：结构化视频素材（分镜补充剪进达人素材，而非纯 AI）。
阶段 5-6W5-W6

③ 爆款素材分析智能体（锚点引擎）

痛点：团队对内容创作「基本没什么认知」，不知道什么素材能跑量。花花的方法论：AI 复刻已经拿到结果的东西，先分析成功概率在哪，再复制。
角色设定：Meta/TK 素材数据分析师，按消耗降序拆解高消耗素材成功要素、升序盘点低效素材避坑。
输入：Meta 后台消耗排序表（高消耗 + 10-15 个低效素材及数据）。
输出：爆款要素拆解 + 投喂给 ①② 的素材模板锚点；可复用到 TK / 亚马逊。
阶段 6W2 起贯穿

三、把智能体打包成 Skill（团队人人能用，跨场景复用）

你们是项目制 / 类中台逻辑：一个站负责人下面带广告、谷歌、社媒、红人、客服一群人。把智能体打包成一句 /触发词，标准同学带的团队就能人人调用——独立站 LB 跑通的同一套能力，可以平移到另一个独立站、TK 小店、3 个亚马逊组。

Skill 1 · 图文素材生成

触发词：/假发图文素材
能力：输入产品 + 爆款锚点 → 一键出 Meta/Facebook 图文素材。
复用：独立站 LB → 另一独立站 → TK 图文 → 亚马逊主图变体。

Skill 2 · 视频素材合成

触发词：/假发视频素材
能力：图片素材 + 达人素材 + 爆款模板 → 结构化混剪视频。
复用：Meta 视频 → TK 视频 → YouTube 测试频道。

Skill 3 · 爆款素材拆解

触发词：/爆款素材拆解
能力：拉后台消耗排序 → 拆高消耗成功要素 + 低效避坑表。
复用：任何渠道、任何品类的素材库都能投喂。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

选「Meta 素材生产 + 验证周报」工作流，因为它正好串起会上定的三阶段：资料收集 → 素材生成 → 市场验证。老板不用看后台，每周拿一份 HTML 报告就知道 AI 素材跑得怎么样、值不值得扩量。

工作流 · Meta 素材生产 + 验证周报（示例）
📥 拉 Meta 后台消耗排序 → 🔍 /爆款素材拆解 → 🖼️ /假发图文素材 → 🎬 /假发视频素材 → 📊 HTML 报告生成器 → 📧 推送李总 + 标准同学
交付物示例（HTML 报告）
• 本周 AI 素材产出量 vs 红人素材成本对比（一条红人素材 ≈ 500 美金 → AI 单条成本）

• 图片 / 视频两条线进度与下周扩量建议
• 独立站 LB 试点结论：是否可以复刻到 TK / 亚马逊
