二、要搭建的 3 个智能体（按首战板块优先级）

花花在场景确认会上明确指定：首战是"双智能体串联"——产品策划+出图，前者输出 {卖点/人群/标题/主图文字} 喂给后者出图。第三个智能体（评价分析升级版）把胡总现在散在 ChatGPT 里的评价分析能力沉淀下来，再反哺策划智能体——形成完整闭环。

① 产品策划智能体

痛点：胡总自述——"我能定卖点、拆人群，但运营、设计 get 不到"；老板亲自盯每张图、产品策划能力无法传递到团队。
角色设定：胡总瑜伽服品类产品经理替身，懂基础款+半标产品逻辑、瑜伽裤人群拆分、面料差异点表达。
输入：一张产品图片（+ 可选：客户抱怨表 / 评价分析结果）。
输出：{产品卖点 + 目标人群 + 产品标题 + 主图可使用文字}——花花指定的标准输出结构。
阶段 5W3-W4首战

② 出图智能体

痛点：胡总自述——AI 换图"拷边线 46 线互变"、衣服长度不稳、"160 克 vs 210 克面料看不出差异"。三运营各自换图无标准。
角色设定：瑜伽服出图执行官，强约束拷边线规范+衣长锁定+面料差异点呈现规则。
输入：策划智能体输出的 {卖点/人群/标题/主图文字} + 产品基础图片。
输出：质性稳定、长度锁定、能承载非标差异的最终图（国内卖点型/跨境白底型按渠道自动切）。

阶段 6W7

三、把智能体打包成 Skill（团队人人能用，跨品牌/跨账号复用）

胡总自己说过（蒋帅管理课消化）："职责拆分 = 能力提炼"。Skill 就是把这件事推到底——把你的策划能力、出图能力、评价分析能力分别打包成 3 个按钮，运营/设计/老板自己都能调用同一个按钮，产出一致。国内三店通用、跨境亚马逊+虾皮通用、未来开新品类（罩衫/短袖）零额外开发。

Skill 1 · 产品策划

触发词：/产品策划 <产品图>
能力：一张图进，输出"卖点+人群+标题+主图文字"四件套——按花花指定的标准结构。
复用：国内瑜伽裤 → 跨境瑜伽服 → 罩衫 → 短袖 通用，改身份层参数即可。

Skill 2 · 出图

触发词：/出图 <策划输出+产品图>
能力：自动套用拷边线规则、衣长锁定、面料差异点呈现，输出可上传的主图。
复用：国内卖点型/跨境白底型按渠道参数自动切，3 个运营 + 设计同事人人能跑。

Skill 3 · 评价分析

触发词：/评价分析 <导出文件>
能力：评价导出→痛点表+新卖点/新人群清单，自动喂回 Skill 1 提示词。
复用：每月跑一次老品复购评价，季度跑一次跨境差评——闭环驱动产品迭代。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

三个 Skill 各自跑能解决"今天写个卖点 / 出个图 / 看看评价"的点；串成"新品策划-出图-验证"工作流之后，从一张产品图到可上架主图，全自动 10 分钟出。胡总不用再盯每张图，新人也能跑。

工作流 · 新品策划-出图-验证 SOP（示例）
🎯 输入：产品图 + 历史评价导出 → /评价分析 → 痛点/新卖点 → /产品策划 → 卖点+人群+标题+文字 → /出图 → 主图终稿 → 📊 HTML 报告生成器 → 📧 推送胡总+设计同事
交付物示例（HTML 报告：新品上架包）
· 评价洞察卡：已覆盖卖点 vs 未覆盖人群（提臀塑形/裸感/菊花裤拆分到位没）
· 策划四件套：卖点 + 目标人群 + 产品标题 + 主图可使用文字
· 出图终稿：国内卖点型 + 跨境白底型 双版本（拷边线 + 衣长 + 面料差异点已锁定）
· 老板审核位：标注"哪些是 AI 自动定的 / 哪些建议人工复核"——让胡总把"亲自盯"切换成"抽查"
