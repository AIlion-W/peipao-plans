二、要搭建的 3 个智能体（按首战板块优先级）

先解决「这个产品到底怎么打」，再解决「图片怎么出」和「详情页怎么承接」。如果跳过定位直接出图，只会得到更多好看的图片，不会得到更清晰的成交策略。

① 产品定位策略智能体

痛点：500 多个产品大多只有一条链接，缺少按人群、场景和卖点拆分的策略。
角色设定：新中式珠宝商品卡策略负责人
输入：产品事实、开品逻辑、客群、历史数据、同行案例、现有素材
输出：目标人群、场景、卖点、关键词、链接定位和素材需求
阶段 5首战阶段首战

② 商品主图出图智能体

痛点：AI 能出图，但产品变形、风格漂移，且缺少点击率假设。
角色设定：珠宝商品卡视觉策略与出图专家
输入：产品白底图、多角度图、定位策略、推广图正负样本和表现数据
输出：主图 / 轮播图 / 佩戴图方案、提示词、测试假设和出图结果
阶段 5-6深化阶段

③ 详情页策划智能体

痛点：现有详情页偏基础，无法承接高客单珠宝的审美、工艺和信任表达。
角色设定：高客单珠宝详情页转化策划
输入：产品定位、材质工艺、客群、佩戴场景、主图策略和竞品详情页
输出：详情页结构、逐屏文案、素材清单和 AI 出图需求
阶段 6固化阶段

三、把智能体打包成 Skill（团队人人能用，跨场景复用）

智能体解决一次判断，Skill 把判断变成团队可以反复调用的工作方式。以后换产品、换系列、换链接时，不需要重新从头教 AI。

Skill 1 · 产品定位

触发词：/产品定位
能力：读取产品资料与数据，输出人群、场景、卖点和链接策略。
复用：珠宝新品、老品重做、不同价格带和不同系列。

Skill 2 · 商品主图

触发词：/商品主图
能力：按定位策略生成主图、轮播图和佩戴图方案及测试假设。
复用：白玉、银饰、花式镶嵌等不同品类。

Skill 3 · 详情页策划

触发词：/详情页策划
能力：把定位策略转成逐屏结构、文案和素材需求。
复用：商品卡详情页、小红书种草页和私域成交素材。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

首个工作流选择「单品多链接生产线」：它最接近当前增长目标，也能直接检验定位、出图和详情页 3 个智能体能否真正协同。

工作流 · 单品多链接生产线（示例）
📦 选择试点产品 → 🧭 产品定位策略 → 🖼️ 主图 / 轮播图生成 → 📄 详情页策划 → 📊 HTML 报告生成器 → 📧 推送相关人
交付物示例（HTML 报告）
① 单品的人群 / 场景 / 卖点 / 关键词 / 链接定位；
② 每条链接对应的主图、轮播图和详情页表达；
③ 每张图的测试假设、素材来源和版本记录；
④ 上线后的点击率、转化率和成交结果复盘。

六、陪跑承诺

① 落地承诺
资料收齐后，陪跑团队带着真实产品和真实数据进入训练，不停留在通用提示词。
② 复刻承诺
先跑通一款产品，再复刻到不同人群、场景、卖点、链接和更多产品系列。
③ 员工承诺
让助理参与资料维护和训练，把老板的判断变成团队可执行、可验收的 SOP。
