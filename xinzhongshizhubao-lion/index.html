一、先建立对 AI 的正确认知

这个项目不是「用 AI 多做几张漂亮图」。真正要解决的是：把老板对产品审美、客群、场景和链接策略的判断，沉淀成团队能重复调用的智能体和工作流。AI 在这里不是美工外包，而是把商品卡上品、打品、测图和详情页策划变成标准化生产线。

二、要搭建的 3 个智能体（按首战板块优先级）

排序依据很简单：商品卡当前最容易直接拿结果。直播基本盘已有复盘工具和切片策略，私域销售潜力大但数据链路还不完整，因此第一阶段先打商品卡。

① 商品卡产品定位策略智能体

痛点：同一个产品可以走不同风格、场景、人群和链接策略，但这些判断现在还没有被结构化。
角色设定：商品卡增长策略师，先判断产品适合什么风格和场景，再决定链接打法。
输入：产品图、产品名、材质 / 工艺、目标客群、历史数据、对标图。
输出：多场景 / 多人群 / 多链接定位表，附主图和详情页方向。
阶段 5首战阶段首战

② 商品主图 / 推广图智能体

痛点：已经能用 AI 出图，但产品容易变形，且缺少高点击率反推标准。
角色设定：视觉增长设计师，先反推对标图元素，再生成可测试图。
输入：定位策略表、产品白底图、模特 / 场景素材、对标图。
输出：主图 / 推广图提示词、出图版本、测试说明和淘汰理由。
阶段 5-6深化阶段

③ 详情页策划智能体

痛点：详情页目前偏简单，无法承接高客单珠宝的审美、信任和价值塑造。
角色设定：高客单珠宝详情页策划，按产品定位组织卖点、场景和信任证明。
输入：产品定位、主图方向、工艺卖点、客群顾虑、历史详情页。
输出：详情页结构、模块文案、图片需求和转化检查表。
阶段 6固化阶段

三、把智能体打包成 Skill（团队人人能用，跨场景复用）

Skill 的价值是把一次会议里的判断，变成每个产品都能调用的标准动作。以后不是每次都问「这张图好不好看」，而是让团队按输入规范得到策略、图片方案和详情页方案。

Skill 1 · 产品定位

触发词：/珠宝产品定位
能力：把单品拆成风格、场景、人群、卖点、链接策略。
复用：可用于新品上架、旧品重做、不同客群链接裂变。

Skill 2 · 主图推广图

触发词：/珠宝主图裂变
能力：根据定位策略和对标图生成主图 / 推广图提示词。
复用：白底图、场景图、人物佩戴图分别形成子模板。

Skill 3 · 详情页策划

触发词：/珠宝详情页策划
能力：把产品定位翻译成详情页结构和素材需求。
复用：按不同产品线复刻，沉淀高客单珠宝详情页 SOP。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

首个工作流建议叫「商品卡上新测试报告」。它不只是给图片，而是给老板和执行同学一个能决策的页面：这个产品走什么策略、出了哪些图、为什么测、下一轮怎么改。

工作流 · 商品卡上新测试报告（示例）
产品资料入库 → /珠宝产品定位 → /珠宝主图裂变 → /珠宝详情页策划 → 📊 HTML 报告生成器 → 📧 推送相关人
交付物示例（HTML 报告）
1. 单品定位：目标人群、场景、风格、卖点、链接策略。
2. 主图方案：每组图的生成逻辑、适用场景、风险点。
3. 详情页方案：模块顺序、信任要素、素材缺口。
4. 测试建议：先测哪几张图、看什么指标、下一轮怎么改。

六、陪跑承诺

① 落地承诺
不做泛泛的 AI 工具体验，第一阶段只围绕商品卡增长，把策略、图、详情页和测试表跑通。
② 复刻承诺
每个有效动作都沉淀成 Skill：同一套逻辑可以复用到更多单品、更多链接和后续渠道。
③ 员工承诺
老板负责判断方向，执行同学按表格和 Skill 操作，逐步把能力从个人经验迁移到团队流程。
本方案基于场景确认会议资料生成。关键判断：该业务不缺产品和审美基础，缺的是把商品卡增长动作系统化，让 AI 从「临时做图」进入「持续产出可测试方案」。
