二、要搭建的 3 个智能体（按首战板块优先级）

花花在场景确认会议里明确："先学 AI，先学图片吧，先把图片再搞定。"——视频是远期。三个智能体按"能不能解决许总最痛的事"排序：性感款打不通 → 风格分层提效 → 视频延展。

① 性感款模特出图智能体

痛点：许总原话"性感款没法拍，没法摆——AI 弄的时候出图率也比较低，很多就出不来"。
角色设定：真丝睡衣性感款模特摄影师，掌握"前开扣/蕾丝吊带"的尺度边界与提示词反推。
输入：产品白底/盒装图 + 风格关键词（性感/中性）+ 人群（30-40 女）+ 场景（卧室/写真）。
输出：可商用模特图（多角度、多场景），含尺度绕过的提示词模板。
阶段 5W3-W4首战

② 风格分层调度智能体

痛点：许总自述"性感的、没那么性感的、不性感的，人群不一样，款式也不一样"——员工目前是"一个款一个款手摸"，效率低。
角色设定：按风格×款式选模型+提示词的"分诊台"，调度智能体 ①。
输入：产品类别（睡裙/两件套/前开扣/盒装）+ 目标人群标签。
输出：直接调用对应风格的"性感款 / 中性款 / 礼盒款"子提示词，一键出图。
阶段 5-6W5-W6

③ 睡衣开箱视频生成智能体

痛点：许总现在小红书博主合作开箱介绍视频"周期慢、费用高"，介绍款式/面料的脚本结构化但每次都重写。
角色设定：把"款式+面料+卖点"模板化为开箱介绍视频脚本+分镜+AI 生成片段。
输入：产品参数（款式/面料/卖点）+ 风格类型。
输出：开箱视频脚本 + AI 生成片段 + 剪辑提示词。
阶段 6W7

三、把智能体打包成 Skill（团队人人能用，跨店铺复用）

许总要的不是"出一张图"，是"团队任何一个员工，输入一个产品，都能出一批合格的模特图"。打包成 Skill 之后，2-3 个店铺、男款/儿童的少量需求都能复用同一套——许总只用统一团队工具栈这一件事，不用反复教。

Skill 1 · 睡衣模特图

触发词：/睡衣模特图
能力：调用智能体 ①，性感款一键出图，提示词模板内置。
复用：云间睡衣坊 2-3 店全部款式；男款/儿童少量需求同一套调用。

Skill 2 · 风格分层

触发词：/图片分层
能力：员工输入产品类别+人群，自动选模型+提示词，调度智能体 ①。
复用：上新批量处理；新员工 5 分钟上手不用学 prompt。

Skill 3 · 开箱视频脚本

触发词：/睡衣开箱
能力：从款式参数生成开箱介绍视频脚本+分镜+AI 片段。
复用：小红书自营内容 + 直播切片素材池。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

许总最该看的不是"我们做了什么"，是"上新一个款，AI 帮我省了多少时间、出了多少图"。每一批上新跑完工作流，自动出一份 HTML 上新报告，对账实拍 vs AI 出图的成本、张数、质检通过率。

工作流 · 单款上新出图流水线

• 待优化点：哪类提示词容易出废图，下一版迭代方向
