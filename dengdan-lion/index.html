二、要搭建的 3 个智能体（按首战板块优先级）

花花在场景确认会上明确：先做文案智能体（已有通用版基础+痛点明确+产出可对比）；再让 AI 梳理"哪些运营工作可以智能体化"，从里面拆第二、第三个。三个智能体最终串成"新品上线"工作流——这条线一通，新人靠按钮就能跑活，解决你义乌运营难培养的根问题。

① listing 文案撰写智能体

痛点：邓丹原话——"提示词是复制过来的，亚马逊培训直接发的，我自己写不出来"；输出常出违禁词需另一软件查再换；字符常超长；五要点想拓到 6-7 行没规则约束。
角色设定：邓丹文具小精品类目 listing 撰写专家，懂违禁词清单 + 字符规则 + 亚马逊五要点拓展规则。
输入：产品基础信息 + 词表（按等级标好）+ 品牌定位 + 竞品参考 ASIN。
输出：标题 + 5-7 行五要点（合规、无违禁词、字符达标、按等级埋词）。
阶段 5W3-W4首战

② 拉词 / 筛词智能体

痛点：邓丹原话——"找竞品、拉词表、筛词表，我总觉得这都是 RPA 干的活，不是人干的"；运营每天大量时间花在 Excel 表格切换、相关性筛选、属性词归类。
角色设定：亚马逊关键词分析师，按"相关性 × 搜索量"两维分级，自动归类属性词 / 人群词 / 场景词 / 功能词。
输入：种子关键词或 5 个竞品 ASIN 拉出的词表 CSV。
输出：分等级词表（第一级 → 标题；第二级 → 五要点；否词清单）+ 属性词分类清单。
阶段 5-6W5-W6

③ 评价属性词提炼智能体

痛点：运营手动复制 QA 问答 → 扔 GPT 分析属性 → 人工对比"我们有没有埋这个词"——重复、易漏、新人做不准。
角色设定：评价洞察专员，从竞品 QA + 用户评价里提炼"防水/耐用/送礼/学生用"等属性词。
输入：竞品 ASIN 或导出的评价/QA 文本。
输出：属性词清单（场景/人群/功能分类）+ 与现有 listing 对比的"埋词查漏补缺建议"。
阶段 6W7

三、把智能体打包成 Skill（团队人人能用，跨场景复用）

Lion 在场景确认会上的判断："前期打磨用智能体把经验讲清楚、捋明白，后面用 Skills 把每一个模块串联起来。"——智能体是单独可用的工具，Skill 是新人也能按一个按钮就触发的"工作机器人"。三个 Skill 之后，跨贴纸店、笔类店、礼品袋类目零成本复用。

Skill 1 · listing 文案

触发词：/listing文案 <产品+词表>
能力：自动套用文具品类违禁词清单、五要点字符规则，输出可直接贴的标题+5-7 行五要点。
复用：贴纸店 → 笔类店 → 礼品袋类目，同一套 Skill 改品类参数即可。

Skill 2 · 拉词筛词

触发词：/拉词 <竞品ASIN | 种子词>
能力：调外部词表软件导出 → 自动按相关性 × 搜索量分级 → 归类属性/人群/场景/功能。
复用：所有亚马逊类目通用，新人无须懂"什么相关性算高"。

Skill 3 · 评价提炼

触发词：/评价提炼 <ASIN>
能力：抓竞品 QA + 评价 → 提炼属性词 → 对比当前 listing 出"埋词查漏建议"。
复用：新品上线前必跑、老品定期复跑（每月/每季度）。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

三个 Skill 单独用能解决"今天写个文案 / 拉个词表"的点；串成"新品上线 SOP"工作流之后，从一个竞品 ASIN 到一份完整 listing 草稿，全自动 5 分钟出。这条线是义乌运营新人也能跑的——你只要把 ASIN 发给 AI，剩下交给工作流。

工作流 · 新品上线 SOP（示例）
🎯 输入：竞品 ASIN ×5 → /拉词 → 分级词表 → /评价提炼 → 属性词 → /listing文案 → 标题+五要点 → 📊 HTML 报告生成器 → 📧 推送邓总+组长
交付物示例（HTML 报告：新品 listing 上线包）
· 竞品对标卡片：5 个 ASIN 的销量、广告结构、能不能打过他的判断
· 词表分级表：标题用词 / 五要点用词 / 否词清单 一目了然
· 属性词查漏补缺：竞品 QA 提炼的属性 vs 我们 listing 已有 → 缺哪些
· listing 终稿：标题 + 5-7 行五要点（违禁词标红已替换、字符数标注）
