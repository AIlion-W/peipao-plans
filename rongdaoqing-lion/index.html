二、要搭建的 3 个工程化模块（按你坚持的优先级）

场景确认会上 Lion 建议先做素材补充（明确见效、不踩反爬），李总坚持先做选品自动化（业务马上见效）——视频为证以你的优先级为准。如果反爬阶段性把选品打掉，立刻切素材方向（已在风险预案里）。三个模块按 1→2→3 顺序上：选品工作流压住业务下滑 → 素材智能体释放 8 人团队 → 非标品视频赶 6 月童装/男装窗口。

① Codex 选品工作流

痛点：李总自述——"5 年肉眼看榜方法失效，100-200 个品才出 1-2 个达千单"；同行 Python 抓 D-1 vs D-2 单量差，命中 10:2-3。
角色设定：选品 SOP 工程师，把 5 年验证的 S+/S/A/B/C 五级分类规则工程化。
输入：抖店罗盘 D-1 vs D-2 爬取数据 + 客户已有筛选 SOP。
输出：按五级分类的趋势款清单（含付费竞争度判断），人工 5h 压到 1h。

阶段 6W7

三、把工程化模块打包成 Skill（团队人人能用，跨账号/跨类目复用）

李总你的难点不是 AI 工具，是"下属推不动"。Skill 是把"老板亲自盯"切成"按一个按钮出结果"——运营/剪辑/编导不需要懂 Codex、不需要懂提示词，按 `/触发词` 就能跑。3 个 Skill 之后，跨抖音/视频号/快手三平台、跨内衣/童装/男装多类目零额外开发。

Skill 1 · 选品自动化

触发词：/选品自动化 <日期>
能力：Codex 跑抖店罗盘 D-1 vs D-2 单量差脚本，按你五级 SOP 自动分类输出趋势款清单。
复用：内衣 → 童装 → 男装 通用，改类目参数即可；反爬挂了由 Codex 持续修 bug。

Skill 2 · 爆款拆解（执行-001 校正）

触发词：/爆款拆解 <竞对视频URL>
能力：拆 TOP 前几名爆款短视频结构（hook 类型/场景/节奏）→ 输出可换场景复刻的脚本草稿。
复用：内衣/童装/男装等多类目通用——TOP 几名永远是参考基线。

Skill 3 · 童男装视频

触发词：/童男装视频 <产品图>
能力：图片拼接 + 款式展示 BGM 模板 + 短剧开头两类自动套用。
复用：6 月童装窗口 → 男装 → 后续非标品扩张，零额外开发。

四、把 Skills 串成"每日选品-素材-视频" SOP，产出千川投流候选包

三个 Skill 各自跑能解决"今天选品 / 找素材 / 出视频"的点；串成"每日选品-素材-视频"工作流之后，早晨一杯咖啡时间，自动产出当天可直接投千川的候选包——李总从"亲自盯榜单"切换成"抽查决策"。

工作流 · 每日选品-素材-视频 SOP（示例）
🎯 早晨 8:00 触发 → /选品自动化 → 趋势款清单 → /素材抓取 → 黄金 3 秒素材包 → /童男装视频 → AI 视频草稿 → 📊 HTML 报告生成器 → 📧 推送李总 + 运营组长
交付物示例（HTML 报告：每日千川投流候选包）
· 选品卡片：今日趋势款 Top 10（按 S+/S/A/B/C 分类、付费竞争度标注）
· 素材包：每款配 5-10 个黄金 3 秒素材切片（已混剪初版）
· AI 视频草稿：童装/男装非标品自动生成 15-30 秒，覆盖短剧开头 + 款式展示
· 老板决策位："今天该投哪几款" + 反爬风险提示（若选品脚本异常自动提醒）
