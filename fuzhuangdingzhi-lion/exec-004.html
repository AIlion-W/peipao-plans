本次会议干了什么

  1. 把产品阶段拆到更小的第一刀。选品 / 平台采集继续后置，先围绕产品流程做两个前置智能体：文案撰写和产品输出。
  2. 现场锁定产品英文标题智能体。输入产品图片 + 中文属性描述，输出英文标题 / 产品特性描述，作为彩页和目录输出的前置模块。
  3. 讲清提示词五层结构。身份层、知识层、工具层、协作层、场景层分别负责岗位定位、经验规则、工具调用、多 Agent 衔接和自动化闭环。
  4. 把标题公式拆成可训练规则。核心款式、属性类目、工艺特点、面料特性、设计细节、字符长度、禁重复和高级表达都要写进提示词。
  5. 明确后续迁移路线。前期用 ChatGPT 打磨智能体，成熟后把指令、知识库和索引逻辑放进文件夹，用 Codex 封装成 Skill。
会议判断 标题智能体不是“翻译器”，而是把产品专员的判断依据写进 AI。

本周核心决策

节奏铁律 先用 3-5 个真实产品把英文标题智能体跑稳，不要直接跳到完整目录册自动化。
首战模块
产品英文标题智能体：产品图片 + 中文属性 → 英文标题 / 特性描述。
提示词结构
身份层、知识层、工具层、协作层、场景层都要写；专属 GPT 也不能省略身份和输入输出。
迭代方式
提示词文件 + 同事试用聊天记录 + 好坏反馈 → AI 修订完整提示词 / MD。
知识库规则
指令里必须写清什么时候调用哪份知识库，面料、尺寸、价格和真实产品资料不能让模型自由编。
