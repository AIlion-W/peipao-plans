二、下一阶段要跑通的 3 个智能体

执行-007 已经确认：当前第一优先级不是新增生图工具，而是把“账号目标 → 内容与数据 → 人工判断 → AI 归因 → 优化动作”跑通。三个智能体都直接服务这一条链路，并以客资与成交作为最终业务验证。

① 内容数据分析智能体

痛点：已有曝光和互动，但为什么没有稳定客资与成交仍说不清；单一时间点数据不足以判断内容。
角色设定：银饰内容增长分析师，按账号目标诊断从曝光、浏览、互动到私信、客资和成交的漏斗断点。
输入：账号目标、单篇内容、24 小时 / 72 小时 / 5—7 天数据、账号整体数据、团队主观判断
输出：做得好 / 不好的具体证据、漏斗断点、图片 / 选题 / 标题 / 文案优化方案、下一轮验证动作
过关标准：连续复盘 3 个真实样本，结论能被运营纠错并转成下一轮发布动作。
带队：Lion / 韩国 × 运营执行
阶段 5当前首战数据驱动

② 账号定位与选题智能体

痛点：矩阵账号目标和调性没有完全拆开，同一内容跨账号重复发布，容易互相抢流量，也无法判断失败来自内容还是账号定位。
角色设定：矩阵账号策略师，为流量小号、蓝 V 获客号分别管理定位、调性、指标和选题边界。
输入：账号历史内容、目标人群、业务目标、近期数据、已验证选题、人工账号判断
输出：账号定位卡、优先指标、可做 / 不做选题、差异化内容清单
过关标准：每个账号都有唯一目标和稳定调性，同一选题能按账号角色做差异化改写。
带队：付华友团队 × 陪跑团队
阶段 5-6一账号一模型

③ 跨平台对标智能体

痛点：小红书图文直接搬到抖音后反馈较弱，但这不能证明抖音图文无效，只能证明平台内对标和选题不足。
角色设定：小红书 / 抖音平台对标研究员，分别学习平台内高表现内容，不把一个平台的模板机械搬到另一个平台。
输入：平台、类目、同行高表现内容、数据、账号定位、团队判断
输出：平台差异、可复用内容规律、对标选题池、测试优先级和验证指标
过关标准：抖音形成独立对标清单，并完成首批平台内图文测试。
带队：运营执行 × 韩国
阶段 6跨平台

三个智能体怎么串成一条线

账号级内容增长闭环
🎯 明确账号目标与调性 → 🔍 平台内对标与选题 → 🖼️ AI 内容生产与发布 → 📊 24h / 72h / 5—7d 数据 → 🧠 AI 归因 + 人工纠错 → 下一轮
为什么是闭环：每轮发布都产生新数据，数据和人工判断继续训练 AI；AI 的优化建议再进入下一轮内容，最终沉淀出每个账号自己的判断模型。
最终验收：曝光和互动只是中间指标；对获客账号，必须继续验证私信、客资和成交，不能把“数据看起来不错”当作业务成功。

三、把稳定方法打包成 Skill

先在真实样本上把输入、判断和输出跑稳定，再封装 Skill。这样团队调用的不是一个“会聊天的工具”，而是一套带账号目标、数据口径和纠错规则的工作方法。

Skill 1 · 内容复盘

触发词：/内容复盘 [账号+笔记+数据]
能力：读取账号目标、单篇内容和分时数据，诊断漏斗并输出下一轮优化动作
复用：同一数据口径下批量复盘，不混淆流量与获客目标

Skill 2 · 账号定位

触发词：/账号定位 [账号+目标]
能力：生成账号定位卡、主要指标、内容调性、可做 / 不做选题边界
复用：20+ 账号分别维护，不让同一内容机械铺满矩阵

Skill 3 · 跨平台选题

触发词：/跨平台选题 [平台+类目]
能力：按平台内高表现对标提炼选题规律、测试清单和验证指标
复用：小红书与抖音分开学习，再判断哪些规律可以迁移

四、把 Skills 串成内容迭代工作流

单个 Skill 是工具，串起来才是业务系统。当前最值得先做的交付物是账号内容复盘 HTML：把每个账号的目标、分时数据、漏斗断点、人工判断和下一轮动作放在同一页，避免团队只看曝光或只凭感觉改提示词。

工作流 · 账号内容数据闭环
🎯 /账号定位 → 🔍 /跨平台选题 → 🖼️ 生成与发布 → 📥 分时数据回收 → 🧠 /内容复盘 → 📊 HTML 复盘 + 下一轮动作
交付物示例（账号内容复盘 HTML）
· 账号定位、当前目标和主要指标
· 单篇笔记 24 小时 / 72 小时 / 5—7 天数据趋势

· 团队判断与 AI 判断的差异、已纠正项
· 下一轮图片、选题、标题、文案和验证动作

五、阶段推进路线

阶段一统一账号目标与数据口径

  • 为每个账号标注平台、定位、当前目标、主要指标和内容调性
  • 统一 24 小时、72 小时、5—7 天分时数据字段
  • 把全账号数据表和最新智能体提示词同步到项目群
账号目标与数据口径表过关：输入资料完整可复盘

阶段二跑通 3 个真实样本复盘

  • 分别选择有曝光无客资、互动较好、蓝 V 有询问无成交的代表样本
  • 同时输入内容、单篇分时数据、账号整体数据和团队判断
  • 逐条纠正 AI 不符合业务的结论，记录提示词变化
内容复盘对话 v1过关：3 个样本可指导下一轮动作

阶段三内容数据分析智能体稳定

  • 固定输入字段、分析顺序、输出模板和不允许越界的判断
  • 把图片、选题、标题、文案优化分别转成可执行动作
  • 用下一轮发布结果验证建议，而不是只做文字评价
智能体 ① 内容数据分析过关：结论可纠错、可验证

阶段四一账号一智能体

  • 先拆流量小号与蓝 V 获客账号，再按内容调性继续细分
  • 每个账号保留自己的历史样本、成功规律和纠错记录
  • 验证不同账号不会机械产出同一批内容
智能体 ② 账号定位过关：账号目标与输出稳定区分

阶段五Skill 化与跨平台对标

  • 封装 /内容复盘、/账号定位、/跨平台选题 3 个 Skill
  • 单独建立抖音银饰图文高表现对标与测试清单
  • 输出账号内容复盘 HTML，团队按同一结构查看与执行
3 个 Skills账号内容复盘 HTML

阶段六业务结果验证与持续迭代

  • 流量账号持续看曝光、互动和涨粉，获客账号继续看私信、客资与成交
  • 每轮只放大被数据验证的内容规律，未验证的结论保留为假设
  • 把复盘结果回喂账号智能体，形成持续学习的内容系统
账号内容增长工作流过关：可持续产生并验证下一轮动作

六、陪跑承诺

① 落地承诺
陪跑团队继续用真实账号、真实笔记和真实数据检查复盘链路，帮助团队把分析转成下一轮内容动作。
② 复刻承诺
方法稳定后封装成智能体 / Skill，让团队按统一口径调用；每个账号保留自己的目标、历史和判断，不做机械复制。
③ 能力承诺
帮助团队掌握“数据 + 标准 + 人工判断 + AI 纠错”的底层方法，让 AI 放大业务能力；不替客户承诺流量、客资或成交结果。
