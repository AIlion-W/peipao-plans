本次会议干了什么

  1. 验收上周作业。侯帅康收齐了市场爆款主图（点击成交率 7.5%~10%）和数据表现不佳的图，会上演示。复盘出过往做法的根本错误——让 AI 生提示词后直接喂产品白底图硬生成，裂变出的新链接点击率、转化率都低。
  2. 定位真正卡点。当前不是数量问题，是质量：清晰度不够（发糊）、素材与鞋子场景/背景/文字融合度差、视觉不立体、整体不协调。客户侧无设计岗，全靠运营助理直接用 AI 生图。
  3. Lion 讲透智能体链路。爆款主图裂变智能体 = 输入爆款主图/产品白底图 → 拆解 → 出报告 → 出裂变方案 → 出图；指令层四段结构：身份层 + 方法层 + 执行层 + 使用边界，知识库补指令 8000 字之外的方法论。
  4. 林韩破解多鞋款难题。针对「每次鞋款不同、智能体输入输出固定」的顾虑，给出解法：把决策点交回人工，用「参考爆款图 + 自己产品白底图」双输入，每次换产品图产出不同结果。
  5. 现场演示通用主图智能体。林韩拿一个做好的通用智能体（输入产品白底图 + 卖点 + 参考图，先反问信息再产出）跑了一遍，验证「以图按指令出图」链路可行，并把智能体 + 提示词直接分享给客户增强体感。
Lion 一句话 智能体没问题，AI 也没问题，有问题的是人对指令的描述——你不告诉它，它就乱来。

本周核心决策

节奏铁律 先稳质量，再上数量。本阶段不要求出图数量，先出一张令客户满意的主图。
智能体目标链路
输入爆款主图/产品白底图 → 拆解 → 出报告 → 出裂变方案 → 出图，中间分步设节点可卡可修正
指令层四段结构
身份层（抖音商品卡卖鞋的运动品牌）+ 方法层（按产品/卖点/人群/需求维度拆解）+ 执行层（分步动作）+ 使用边界（只适用鞋子商品卡）
多鞋款怎么办
决策点交回人工：参考爆款图 + 自己产品白底图双输入，每次换产品图产出不同结果
喂 AI 的前提
把「看起来高级/立体」拆成客观维度：特效、景深、留白率、主体清晰、产品角度、背景
数据口径
抖音只能拿点击次数 + 点击成交转化率 + 成交件数，重点看点击成交转化率
起步方式
先用林韩分享的通用智能体找体感，再自建一套属于自身业务的，1.0→2.0 持续迭代
