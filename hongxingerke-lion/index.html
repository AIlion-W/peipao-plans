一、先建立对 AI 的正确认知

AI 不是一个"更聪明的搜索框"，也不是"降本工具"。AI 是把蒋总你和你团队里所有人的经验、方法论、SOP，沉淀成一条可以横向复刻、永远在岗、不会离职、不会忘记的生产线。这跟你"把鸿星尔克跑通的模式复制到 361/耐克/安踏"的思路是同一件事——只是这次复刻的是"人"。

二、要搭建的 3 个智能体（5-22 场景确认会议锁定）

花花老师当场拍板：先素材，后直播；先横向拓，再纵深做工作流。三个智能体都围绕"短视频素材 AI 化"——你 5-22 当天试 361 一条 ROI 12 已经证明模式可行，现在要做的是把"找到爆款 → 反推生成 → 自动裂变"做成 SOP，先 361 跑通后横向复刻鸿星尔克/耐克/斯凯奇/安踏。

① 爆款视频分析智能体

痛点：盯同行靠人刷，常常爆 2-3 天才发现；自家发布的视频好坏复盘靠拍脑袋。
角色设定：体育鞋抖音爆款拆解师 + 已发布数据复盘师。一个智能体做两件事（5-22 花花当场合并）。
输入：同行爆款视频链接 / 自家发布视频 + 后台数据（播放、转化、ROI）
输出：① 爆款元素拆解（前 3 秒钩子 / 中段卖点 / 收尾结构）② 自家视频好坏归因报告（哪条该裂变、哪条该停掉）
对照你 5-22 提的："这条视频前三秒手指指向鞋，中间用户+卖点，后面收尾"——让 AI 把这套拆解逻辑标准化、对每条爆款自动跑一遍。
带队：林韩主带 × 视频负责人执行
阶段 5W2-W3首战 #1

② 爆款模板反推 → 视频生成链路

痛点：5-22 当天 361 那条爆款是"同行框架改的"，但改的过程靠经验，没法快速复制；模板用爆率随次数衰减。
角色设定：爆款视频反推提示词师 + AI 视频生成执行器。把"爆款 → 提示词 → 生成"做成一条链路。
输入：智能体 ① 输出的爆款拆解 + 当周要推的产品（如 361 跑鞋一口价 399）
输出：可直接喂给 AI 视频工具的完整提示词（人物 / 场景 / 镜头 / 台词模板）+ 1 条生成出的可发视频
对照你 5-22 提的："门店打完折 600 多，直播间到手只要这个数"——这种台词结构反推成模板，下次换产品换价格直接套。
带队：Lion 主带（工作流/Codex 一阶段先纯提示词） × 视频负责人执行
阶段 5W3-W4首战 #2

③ 爆款视频裂变智能体

痛点：你 5-22 自己提的——"一个模板丢进去，能不能设置变量自动生成多条？" 现在靠人逐条调提示词，工作量大。
角色设定：基于产品参数+人群变量自动改写爆款脚本的批量生产器。
输入：跑通的爆款脚本（来自智能体 ②） + 变量表（产品段位 / 性别 / 场景 / 价格区间）
输出：一次出 N 条差异化脚本 + 配套画面建议（如 361→奥迪段位、斯凯奇→劳斯莱斯段位、男鞋配豪车、女鞋配美女、男女同款配情侣场景）
对照你 5-22 讲的策划公式：智能体内置"鞋类×段位→车型映射表"+"性别→场景映射表"，这就是你脑子里那套方法论的 AI 副本。
带队：培培 × 执行团队（W5 准备好后 Lion 接入做工作流串联）
阶段 5-6W5-W6首战 #3

三个智能体怎么串成一条线

爆款视频生产链路（三智能体闭环）
📥 收集：3-5-7 条自家爆款 + 3-5-7 条同行爆款 → 🔍 智能体 ① 拆解为什么爆 → 🧬 智能体 ② 反推提示词→生成 1 条新视频 → ⚡ 智能体 ③ 一键裂变 N 条 → 📊 智能体 ① 复盘 → 喂回 ②③
为什么是闭环：智能体 ① 既是入口（拆同行爆款）也是出口（复盘自家发布），把自家发布数据回喂给 ②③ 做迭代——这就是 5-22 花花说的"分析+复盘合一"的真正用法。
先用对话调好，再做工作流：5-22 花花原话——"提示词调优本质是为了让结果更好，先把对话跑好，再做工作流串联"。所以 W2-W4 三个智能体先用 GPT 对话框跑通，W5 起 Lion 用 Codex/Skill 串成自动化。

三、把智能体打包成 Skill（团队人人能用，跨品牌复用）

智能体只是"一次性的流水线"，Skill 是"装进口袋的流水线"——任何一个员工，在任何一个项目里，喊一声 /视频脚本工厂 鸿星尔克 就能直接出活。这是你"鸿星尔克 → 361 → 耐克 → 安踏"复刻能力的真正杠杆。

Skill 1 · 爆款拆解

触发词：/拆爆款 [视频URL]
能力：抓取视频 → 切前/中/后段 → 输出爆款元素结构化报告
复用：拆同行也拆自家，4 个品牌通用

Skill 2 · 模板生成视频

触发词：/生视频 [模板ID] [产品+价格]
能力：调出反推好的提示词模板 → 套入当周产品参数 → 出可发视频
复用：模板库越攒越大，生产速度指数级

Skill 3 · 一键裂变

触发词：/裂变 [爆款ID] [变量N]
能力：基于段位/性别/场景映射表 → 自动出 N 条差异化脚本
复用：一条爆款 → 10 条变体，跨品牌全自动

四、把 Skills 串成工作流，产出每周爆款监测+生产 HTML 报告

单个 Skill 是工具，串起来才是业务系统。下面是"每周爆款监测 + 视频日产"工作流的样子——团队不再靠人刷同行（5-22 你提的"爆 2-3 天才发现"问题），每周一早上你打开邮箱就能看到一份 HTML 报告：上周爆款拆好了、本周该裂变哪几条、模板已经生成视频等审核。

工作流 · 每周爆款监测+日产视频（W5+ 阶段交付）
🔍 抓取上周同行 TOP 10 + 自家发布数据 → /拆爆款 批量 → 🎯 命中本周产品的爆款模板 → /生视频 套当周价格 → /裂变 N=5 → 📊 HTML 周报 + 待审核视频包 → 📧 推送视频负责人+蒋总
