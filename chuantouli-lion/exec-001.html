本次会议干了什么

  1. Obsidian 落地扫盲。现场带罐子安装 Obsidian、打通 Codex，装好核心插件——getGit（本地改动自动同步 GitHub）、WeRead 微信读书、HTML Reader、沉浸式翻译。讲清 Obsidian 本质：MD 文件的本地「阅读器 + 知识库」，省 token、对 AI 友好。
  2. 解决 Skills 跨系统分发。罐子痛点是「Mac 本地复制 skill 给 Win 员工失效」。Lion 给出新路径：Skills 推 GitHub 仓库，员工 clone 直接调用、保持原生态；上传前让 Codex 声明「适配所有系统」即可跨 Win/Mac。
  3. Skills vs Computer Use 选型纠偏。罐子的平台测算用 Computer Use 反复犯同样卡点、记不住——根因是 MCP 控屏逻辑无法沉淀。结论：能用 Skills 绝不用 Computer Use；Computer Use 只做探索，跑通后梳理成文字转 Skills。
  4. 生图脚踏排坑（罐子原创）。「脚踏」中文词被模型当动词→人物悬空；改英文 peddle 或中文「脚踏板」名词化即解。九宫格批量同风格出图判定为模型上限，等升级。
  5. 敲定自动化运营路线。Python 脚本（截图 + 地址喂 Codex 生成）抓取竞品/后台 → Cron 定时 → 数据分析 Skills → 飞书 CLI 推送。可让 Codex 学盗版运营课精简方法论，变「成熟运营」。
