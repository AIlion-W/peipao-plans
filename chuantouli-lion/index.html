二、要收口的 3 个智能体（按你当前的首战顺序）

排序依据你自己的原话——「我现在需求挖得差不多了，接下来要做自动化」。所以第一优先是自动化运营；第二是你反复提的「飞书解决不了」的微信文案库；第三是你已起步的跟品分析。

① 自动化运营智能体

痛点（罐总原话）：「让后台他每天代替我的运营，去给我抓东西做分析，到点给我」「还没实现自动化的全平台抓取」
角色设定：替代人工运营，每日定时抓取竞品/后台数据并出分析
输入：竞品/后台页面地址 + 操作流程截图 + （可选）盗版运营课蒸馏的方法论
输出：Python 脚本 + Cron 定时 + 飞书 CLI 推送日报
阶段 7W1-W3首战

② 微信文案库检索智能体

痛点（罐总原话）：「把微信好文章变成我的 AI 记忆……skill 自动检索……帮我写文案，这是飞书给我解决不了的」
角色设定：文章链接 → 本地文案/选题库 → skill 检索喂料写文案
输入：公众号/朋友圈文章链接（合规下载，避微信反爬）
输出：结构化文案库 + 按选题自动检索的素材包
阶段 6-7W4-W5

③ 跟品分析智能体

痛点（罐总原话）：「抓竞对今天/昨天/前天的销量增量，再做分析，哪个爆了我想卖哪个」
角色设定：抓竞品销量/增量做跟品决策分析
输入：竞品页面 / 类目榜单
输出：跟品数据报告（增量趋势 + 选品建议）
阶段 7W6-W7

三、把智能体打包成 Skill（员工人人能用，跨平台复用）

你已经在做这件事了——做完 skill 让 Codex 生成 MD 文档给员工复制。这一步我们升级：用 GitHub 仓库做 Skills 跨系统分发，员工 clone 直接调用、保持原生态，你不用再手动复制文件夹（Mac→Win 也不再失效）。

Skill 1 · 自动运营日报

触发词：/运营日报
能力：Python 抓取 + 数据分析 + 飞书 CLI 推送
复用：换页面地址即可迁到全平台（小红书/抖音/京东）

Skill 2 · 文案蒸馏

触发词：/文案蒸馏
能力：文章/逐字稿 → 方法论蒸馏 → 入文案库
复用：任意博主蒸馏（如你说的「江湖说 470 篇」）

Skill 3 · 跟品分析

触发词：/跟品分析
能力：竞品销量增量抓取 + 趋势分析 + 选品建议
复用：任意品类/平台，给品牌方也能用

四、把 Skills 串成工作流，产出可交付的 HTML 报告

选「每日自动化运营日报」做示例——这正是你说的终极目标：「只要我电脑开着，他就自动运转」。Cron 定时触发，全程无人值守，到点把分析结果推到你飞书。

工作流 · 每日自动化运营日报（示例）
⏰ Cron 定时触发 → 🐍 Python 抓取竞品/后台 → /跟品分析 算增量 → /运营日报 出洞察 → 📊 HTML 报告生成器 → 📧 飞书 CLI 推给罐总
交付物示例（HTML 日报）
• 竞品昨日 vs 前日销量增量榜 + 爆品预警
• 自家各平台后台核心指标对比（点击/转化/客单）
• 今日「值得跟」的品 Top 3 + 跟品理由
• 异常项人工复核清单（AI 不确定的交给人判断）
