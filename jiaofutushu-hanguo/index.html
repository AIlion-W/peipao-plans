一、先建立对 AI 的正确认知

你们其实不是"还没用 AI"的公司——组稿校对、数字人录课、短视频 AI 开头混剪、电商主图、影刀自动化、飞书智能体，AI 已经渗进编辑端和营销端。问题在于：这些能力都还停在"会用工具"这一层，分散在不同同事手里，没有被打包成一个个能稳定复用、跨店复制的"智能体"。接下来两个月，我们做的不是教你用新工具，而是把你公司最值钱的经验——尤其是选题——从"老师傅脑子里的判断"沉淀成 AI 能一起干的系统。

两个月终态

二、要搭建的 3 个智能体（按首战板块优先级）

花花老师在会上定的顺序很清楚——"先从推广图裂变开始，因为这个离业务最近，而且反馈最快"。所以排序不是按价值高低，而是按"哪个最快能看到结果、最快建立团队信心"。选题智能体价值最高（你自己说"选题对我们是最重要的"），但它要先拆工作流，放到后面慢慢啃。

① 推广图裂变智能体

痛点：宋总说"目前做推广图只能人工，想利用 AI 做裂变但不知元素拆解如何下手"（前景/后景/卖点位置）。
角色设定：拼多多推广图裂变手——不做优化、不做创造，只在已验证的产品图基础上裂变出多版主图。
输入：一张产品图（已有的主图 / 卖点图）。
输出：多张不同类型推广图，供测点击。核心指标 = 可测素材数量。
阶段 5W3-W4首战

② 爆款视频复盘智能体

痛点：你们做了大盘起量视频汇总和素材分类，但复盘靠人，难沉淀。花花："至少让一个聪明的大脑帮你做数据积累"。
角色设定：爆款视频分析师——喂视频内容 + 数据，做复盘与规律提炼。
输入：爆款视频 + 一系列数据指标。
输出：复盘结论 + 可复用的视频类型/钩子规律（配合视频类型分类）。
阶段 5-6W5-W6分支线

③ 选题（选品）智能体 · 拆分

痛点：宋总自述"选题对我们是最重要的，你选题不好运营再牛也玩不出花"，但选题逻辑全在脑子里，来源宽泛分散、靠经验判断。
角色设定：基于过往经验总结规律 + 裂变选题。拆成主图分析出选题 / 详情页出选题 / 评价出选题等子智能体。
输入：渠道信息（小红书 / 拼多多截图等）+ 历史选题表格留痕。
输出：选题建议清单，供选题委员会过会。
阶段 6W7最高价值

三、把智能体打包成 Skill（团队人人能用，跨店复用）

你们一年 4-5 亿、拼多多 13-15 个店——同一个能力如果只活在一个同事的对话框里，就只能服务一个店。打包成 Skill，意味着一次搭好，营销、设计、产品编辑部任何人敲一个 /触发词 就能调用，13-15 个店、天猫京东新媒体全平台复用同一套标准。这正是你们做"复刻"最擅长的逻辑，只是把它用在了工作流上。

Skill 1 · 推广图裂变

触发词：/推广图裂变
能力：丢一张产品图，输出多版可测推广图。
复用：拼多多 13-15 店 + 天猫 / 京东全平台主图测试。

Skill 2 · 视频复盘

触发词：/视频复盘
能力：喂爆款视频 + 数据，出复盘 + 类型规律。
复用：抖音 / 快手 / 视频号每条起量视频都能进复盘。

Skill 3 · 选题策划

触发词：/选题策划
能力：渠道信息 + 历史经验 → 选题建议。
复用：产品编辑部全员选题策划提速，沉淀公司选题资产。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

单个 Skill 是点，串起来才是你们要的"中枢和大脑"——花花在会上说的"智能场景智能体清单"就是这个中枢的起点。下面用"新品上架内容生产线"做示例：从选题到出图到视频到复盘，AI 把一条龙串起来，最后自动出一份给管理层看的 HTML 报告。

工作流 · 新品上架内容生产线（示例）
💡 /选题策划 出选题 → 🖼 /推广图裂变 出多版主图 → 🎬 视频类型分类 + AI 生成 → 📈 /视频复盘 回流数据 → 📊 HTML 报告生成器 → 📧 推送选题委员会 / 运营
交付物示例（HTML 报告）
· 本批选题来源与通过/否决理由（选题委员会留痕结构化）
· 每个新品的推广图测试矩阵 + 点击率排序
· 爆款视频类型分布与复盘结论（哪类钩子起量）
· 下一批选题与素材方向建议（AI 裂变给出）

五、两个月周里程碑

节奏按花花会上说的来——"两个月一个场景一个场景去推动，如果速度快全部能做完，慢的话不会卡这个时间点"。下面是参考节拍，实际以你们推进速度为准。

W1认知打底 · 清单立项

  • 会后宋总把场景智能体清单 + 会议文档 + 会议文字发群，给 AI 一句提示词出执行计划（中枢大脑起点）
  • 培培老师出"智能场景智能体清单"，明确三大模块各要做什么、怎么做
  • 韩国老师 + 考拉老师对齐项目，确认推广图裂变首战范围
交付：智能场景智能体清单

W2知识层入库 · 推广图元素拆解

  • 收集已验证的产品主图 / 卖点图样本，明确"前景 / 后景 / 卖点位置"拆解口径
  • 选定一个拼多多重点店 / 重点品作为首个裂变试点
推广图素材库 v1

W3-W4智能体 ① 上线 · 推广图裂变

  • 搭推广图裂变智能体：一张产品图 → 多版推广图
  • 跑首批测点击，按反馈迭代裂变规则；打包成 /推广图裂变
智能体 ①Skill /推广图裂变

W5-W6智能体 ② 上线 · 视频复盘 + 类型分类对接

  • 把传统视频类型分类与 AI 视频生成逻辑结合，给视频小组更清晰策略（做几类、各多少量、混剪结果）
  • 搭爆款视频复盘智能体；整理完由韩国老师过一遍给建议
智能体 ②Skill /视频复盘工作流HTML 报告

W7智能体 ③ 上线 · 选题智能体拆分

  • 拆解原选题工作流：渠道信息 → 选题委员会留痕的输入输出
  • 先做一个子智能体（如"主图分析出选题"或"评价出选题"）跑通，再横向复制
智能体 ③Skill /选题策划

W8业务系统化 · 串生产线

  • 三个智能体串成"新品上架内容生产线"，跨拼多多多店复用验证
  • 沉淀智能场景智能体清单为公司 AI 项目中枢；结业 HTML 报告
