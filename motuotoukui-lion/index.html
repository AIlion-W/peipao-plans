二、要搭建的 3 个智能体（按首战板块优先级）

这个排序是 2026-06-03 执行会议上洪总自己定的——"选题是第一步，标题这些反而比较简单"。选题是自媒体最关键、你最熟、历史数据最全的板块，所以第一刀就切它，再横向复制到标题、文案。原定的 AI 视频素材降为并行推进，不放弃。

① 小红书选题智能体

痛点：洪总自述"现阶段就是不断地有题，你得有题才会吸引人"；一天只能产 5-6 条，要扩号产能严重不足。
角色设定：懂复古摩托头盔人群的资深小红书选题策划
输入：历史选题数据分类（每条笔记标题 + 近 7/24 天小眼睛）+ 产品卖点/人群 + 参考爆款（指明只参考人群/话术/热点）
输出：贴合产品的选题方向清单 + 每条选题的参考逻辑
阶段 5W3-W4首战

② 小红书标题智能体

痛点：标题目前靠豆包 + 竞对标题库散点拼凑；但你手里有大量带真实数据的历史标题——这是天然好语料。
角色设定：吃透你账号数据的标题工程师
输入：选题 + 历史高数据标题库（带小眼睛数据）+ 卖点
输出：多版可 A/B 的标题候选 + 预估吸引点
阶段 5-6W5-W6

③ 小红书正文 / 评论智能体

痛点：助理写正文 + 补评论区基础评论耗人力；发帖率上不去（想从一天 5-6 条往上提）。
角色设定：小红书正文 + 评论区话术写手
输入：选题 + 标题 + 卖点/人群
输出：成稿正文 + 评论区基础话术
阶段 6W7

三、把智能体打包成 Skill（团队人人能用，跨场景复用）

林韩在会上说得很清楚——"我们这个 AI 培养完了，它是可以复制的、可以沉淀下来的，不是出完就忘记"。把每个智能体封装成一个 /触发词，运营、助理打开就能用；同一套选题逻辑，6 个号能用，将来 50 个号、斜挎包/衣服新品类也能用。

Skill 1 · 选题

触发词：/选题
能力：投喂参考素材 + 产品信息，一键出贴合人群的选题方向
复用：6→50 号矩阵通用；品类拓展（斜挎包/衣服）换知识库即可

Skill 2 · 标题

触发词：/标题
能力：基于历史高数据标题库，给选题出多版标题
复用：所有小红书号 + 未来抖音/天猫主图文案场景

Skill 3 · 小红书文案

触发词：/小红书文案
能力：选题 + 标题 → 成稿正文 + 评论区话术
复用：矩阵号批量发帖；新品类内容直接套

四、把 Skills 串成工作流，产出可交付的 HTML 报告

三个智能体单独用已经省力，串起来就是一条"小红书发帖生产线"——这正对你"6→50 号矩阵缺产能"的核心瓶颈。

工作流 · 小红书一条龙发帖（示例）
🎯 /选题 → ✍️ /标题 → 📝 /小红书文案 → 🖼️ 配图/视频素材（Lovart 并行） → 📊 HTML 发帖日报 → 📧 推运营
交付物示例（HTML 发帖日报）
· 本周可发选题清单（按人群/话题分类 + 参考逻辑）
· 每条选题配 2-3 版候选标题 + 成稿正文 + 评论区话术
· 预估对标爆款的数据参照（近 7/24 天小眼睛区间）
· 一键分发到 6→50 号矩阵的排期建议
