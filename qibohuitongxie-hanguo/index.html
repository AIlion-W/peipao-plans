一、先建立对 AI 的正确认知

七波辉的打法本质是"复刻"——把一条跑通的爆款视频，复制成一条生产线。AI 陪跑做的是同一件事：把丁脑子里的拍摄审美、把那条跑出过爆款的经验，从"只在你手上"变成"任何人调用都自带这套经验"。Lion 这次说透了底层逻辑——智能体就是一套提示词，你迭代的是它的指令；我们这两个月，就是帮七波辉把"一次性的好运气"沉淀成"可复用的好资产"。

二、要搭建的 3 个智能体（按首战板块优先级）

排序依据本周共识：先把"分析"做透（知道好视频好在哪），再固化"生成"（即梦提示词），最后沉淀"拍摄经验"（让丁一人的审美变成团队能力）。Lion 的铁律是——每个智能体足够垂直，一个智能体只解决一个事。

① 短视频爆款分析智能体

痛点：丁自述"早期跑出过一条优质 AI 素材，后续复制效果不稳"——爆款好在哪说不清，无法复制。
角色设定：短视频数据分析师，基于心理学等机制原理，从人群/卖点/需求/场景多维拆解。
输入：视频原素材 + 客观数据 + 账号信息 + 人群定位 + 正反案例。
输出：多维诊断报告 + 可复用的"爆款要素清单"。
阶段 5W1-W2首战

② 即梦视频生成 / 复刻智能体

痛点：镂空鞋出现空脚/凭空多鞋幻觉，鞋底纽扣细节失真，出图还得逐张调"影响速度"。
角色设定：即梦分镜脚本师，用自然语言+看图写话，规避幻觉、@ 细节图。
输入：参考视频/商品图 + 镂空鞋多角度上脚图 + 鞋底/纽扣细节图。
输出：分镜脚本 + 即梦提示词（0 秒也填满、口播非字幕）。
阶段 5-6W3-W5

③ 拍摄经验智能体

痛点：丁是唯一摄影同学，拍摄角度/光线的审美经验全在脑子里，黄金龙团队无法复用。
角色设定：童鞋拍摄顾问，沉淀已知 + 聊出未知，整合成完整拍摄 SOP。
输入：拍摄经验对话/录音逐字稿 + 对标账号拍摄拆解。
输出：拍摄角度/光线/场景 SOP，下面的人传视频即可获指导。
阶段 6W6-W7

三、把智能体打包成 Skill（团队人人能用，跨账号复用）

智能体打磨满意后，"把链接分享给同事就能用"——Skill 化就是让丁一个人的经验，变成黄金龙福建团队、变成每个新账号都能直接调用的标准动作。

Skill 1 · 爆款诊断

触发词：/爆款诊断
能力：传一条视频 + 数据，输出多维拆解 + 要素清单。
复用：所有童鞋账号、新老号都可用同一套诊断标准。

Skill 2 · 即梦脚本

触发词：/即梦脚本
能力：传商品图+参考视频，出分镜脚本+即梦提示词。
复用：换款式只换素材，提示词逻辑一套通用。

Skill 3 · 拍摄 SOP

触发词：/拍摄SOP
能力：传待拍款式，给角度/光线/场景建议。
复用：福建团队照着拍，不依赖丁亲自到场。

四、把 Skills 串成工作流，产出可交付的 HTML 报告

三个智能体单独用是工具，串起来就是一条"AI 视频生产线"——这正是赛马式推进要的东西：每条视频都走同一条流水线，数据回流再喂养智能体，越跑越准。

工作流 · AI 视频生产线（示例）
🎯 对标爆款 → /爆款诊断 → /拍摄SOP + 拍摄 → /即梦脚本 + 生成 → 📊 HTML 报告生成器 → 📧 推送相关人
交付物示例（每周 HTML 视频复盘报告）
• 本周各账号视频数据排行 + 爆款/扑街对比拆解
• 命中的"爆款要素"清单 与 上周对比的迭代点
• 下周对标方向 + 待拍款式的拍摄 SOP 建议
• 智能体指令本周新增/优化记录（沉淀可追溯）
